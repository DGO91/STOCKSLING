# BLUEPRINT OFICIAL DE DESARROLLO: STOCKSLING (SAAS MULTIMEDIA)

Este documento contiene la arquitectura de software, el mapa de directorios, la lógica de negocio y las directrices de ingeniería para construir **StockSling**, un SaaS automatizado y autosuficiente para la indexación y subida masiva de material de stock en 2026.

---

## 1. ESPECIFICACIONES Y OBJETIVOS DEL SISTEMA
*   **Nombre Comercial:** StockSling
*   **Propósito:** Automatizar la indexación SEO multimedia (Fotos RAW/JPEG y Vídeos 4K/ProRes/MP4/MOV) mediante la IA de Claude (Anthropic), gestionar autorizaciones de modelos de forma inteligente y distribuir los archivos en paralelo sin pérdida de calidad mediante conexiones asíncronas FTP a Adobe Stock y Shutterstock.
*   **Filosofía:** Sistema 100% autoservicio, libre de soporte humano y auto-reparable (Self-Healing) ante cambios de las agencias de stock.

## 3. REGLAS SAGRADAS DE INGENIERÍA PARA LOS AGENTES
1.  **Conservación Binaria No Destructiva:** Prohibido re-comprimir píxeles en el servidor. Las fotos inyectan metadatos IPTC/XMP a nivel binario con ExifTool/ImageMagick. Los vídeos se transmiten idénticos de manera nativa (`-c copy`).
2.  **Flujo Desacoplado por Miniaturas:** La IA de Claude solo procesa copias ligeras de 1024px extraídas localmente en el navegador (fotos) o mediante FFmpeg en el segundo `00:02` (vídeos).
3.  **Subidas Directas por URLs Firmadas:** El frontend usa URLs firmadas de Amazon S3 o Google Cloud Storage para que los archivos ProRes o RAW gigantes viajen directamente del navegador a la nube sin pasar por la RAM del servidor web.
4.  **Cero Bloqueos:** Todo el backend opera asíncronamente (`FastAPI`, `SQLAlchemy`, `aioftp`, `aiofiles`). Las tareas pesadas se delegan a colas con Redis/Celery.

### MÓDULO 2: Cifrado Militar AES-256-GCM para Credenciales FTP (vault.py)
```python
import os
from base64 import b64encode, b64decode
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

class CredentialEncryptor:
    def __init__(self):
        self.key = b64decode(os.environ.get("MASTER_ENCRYPTION_KEY"))
        self.aesgcm = AESGCM(self.key)

    def encrypt_data(self, plain_text: str) -> str:
        nonce = os.urandom(12)
        encrypted_bytes = self.aesgcm.encrypt(nonce, plain_text.encode('utf-8'), None)
        return b64encode(nonce + encrypted_bytes).decode('utf-8')

    def decrypt_data(self, encrypted_base64: str) -> str:
        payload = b64decode(encrypted_base64.encode('utf-8'))
        return self.aesgcm.decrypt(payload[:12], payload[12:], None).decode('utf-8')
```

### MÓDULO 3: Telemetría, Diagnóstico y Soporte 100% Autónomo (ai_support_agent.py)
```python
from datetime import datetime
from pydantic import BaseModel

class IncidentReport(BaseModel):
    incident_code: str
    user_id: str
    file_id: str
    technical_error: str
    user_diagnostic: str
    antigravity_action: str

def generate_incident_diagnostic(user_id: str, file_id: str, raw_error: str) -> IncidentReport:
    timestamp = datetime.now().strftime("%Y%m%d-%H%M")
    incident_code = f"ERR-{user_id[:8].upper()}-{file_id[:8].upper()}-{timestamp}"
    error_lower = raw_error.lower()
    
    user_msg = "Error inesperado en los servidores de la agencia. Procesando solución automática."
    ag_action = "TRIGGER_SELF_HEALING_AGENT"

    if "530" in error_lower or "authentication failed" in error_lower:
        user_msg = "Tus credenciales FTP de la agencia son incorrectas en tu perfil."
        ag_action = "NOTIFY_USER_CREDENTIALS"
    elif "duration" in error_lower:
        user_msg = "El vídeo no cumple con la duración permitida de 5 a 60 segundos."
        ag_action = "REJECT_FILE_FORMAT"

    return IncidentReport(
        incident_code=incident_code, user_id=user_id, file_id=file_id,
        technical_error=raw_error, user_diagnostic=user_msg, antigravity_action=ag_action
    )
```

## 5. REQUISITOS ECONÓMICOS Y DE GAMIFICACIÓN
*   **Equivalencia de Consumo:** 1 Foto procesada = 1 Crédito // 1 Vídeo procesado = 5 Créditos (por costes variables de red y CPU).
*   **Planes Mensuales:** Starter (Free/25 créditos) | Casual ($14.99/150 créditos) | Pro ($49.99/600 créditos + FFmpeg) | Agencia ($129.99/2,000 créditos + Red ilimitada).
*   **Estrategia de Referidos:** Bucle Dual. Invitar a un amigo otorga 50 créditos gratis al remitente y expande el Free Tier del invitado a 50 créditos iniciales. Condición de liberación en DB: El invitado debe completar con éxito su primera subida FTP real.
