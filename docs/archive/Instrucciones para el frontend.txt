El objetivo de UX es el "Flujo sin fricción": que el fotógrafo complete la subida masiva de 100 fotos en menos de tres clics.Aquí tienes el diseño estructural de las 3 pantallas clave de tu MVP, optimizadas para el flujo de trabajo con la IA de Claude y tus microservicios de Docker.Pantalla 1: El Área de Carga (Dashboard)Es la pantalla de inicio tras iniciar sesión. Debe ser limpia para no abrumar visualmente.Zona Central (Drag & Drop): Un rectángulo grande con bordes punteados que reacciona visualmente cuando arrastras archivos.Texto guía: "Arrastra tus fotos RAW o JPEG aquí o haz clic para explorar".Visual Anchor: Un icono grande de una nube de carga 📥.Selector de Destinos (Barra Lateral Izquierda):Interruptores (Toggle switches) visuales con los logos de las agencias: [ Adobe Stock ] [ Shutterstock ] [ Getty Images ].El usuario activa o desactiva las agencias a las que quiere enviar el lote actual antes de soltar las fotos.Comportamiento UX: Al soltar los archivos, la pantalla no se bloquea. Se activa el script de JavaScript anterior, mostrando barras de progreso individuales para cada archivo subiendo directamente a tu S3 en la nube.Pantalla 2: El Espacio de Trabajo (Revisión de Metadatos)Una vez que las fotos están en la nube, el sistema redirige al usuario a la pantalla de curación, donde la IA de Claude ya está trabajando en segundo plano.Diseño de Panel Partido (Split-Screen):Lado Izquierdo (Cuadrícula de Fotos): Muestra miniaturas de las fotos que se están procesando. Cada foto tiene una pequeña etiqueta de estado:Efecto de carga: "Analizando con IA..." (Color amarillo).Icono Check: "Listo para envío" (Color verde).Lado Derecho (Editor Inteligente): Al hacer clic en cualquier miniatura del lado izquierdo, el lado derecho se rellena instantáneamente con el JSON devuelto por Claude.Campos del Editor Inteligente:Input de Título: Texto corto precargado por Claude. Editable si el fotógrafo quiere un ajuste manual.Input de Descripción: Un cuadro de texto optimizado para SEO.Caja de Tags (Keywords): Las 40-50 palabras clave se muestran como "burbujas" o tags individuales con una "X" para eliminarlas rápidamente. Incluye un botón para "Añadir Tag manual".Sección de Alerta de Contratos (Model Release):Si Claude marcó requires_model_release: true, el panel derecho muestra una alerta visual (Fondo naranja suave).UX intuitivo: Un menú desplegable que dice: "Selecciona el contrato para esta foto", conectado con la biblioteca de PDFs guardada del fotógrafo. Incluye un botón rápido para "Subir nuevo contrato".Pantalla 3: El Historial y Confirmación (Panel de Control de Envíos)Cuando el fotógrafo revisa todo y pulsa el botón principal "Enviar Lote Completo", el sistema lo mueve al monitor de estado.El Botón de Acción Principal: Debe ser grande, de un color llamativo (ej. Verde esmeralda o Azul eléctrico) colocado en la esquina inferior derecha.Lógica de Estados en Tiempo Real (Websockets): Una tabla o lista que muestra los lotes enviados. El fotógrafo puede ver cómo el script asíncrono aioftp de tu contenedor Docker va enviando los archivos uno a uno:Foto_01.CR3 ───► Enviando a Adobe Stock (45%) [Barra de progreso].Foto_02.JPG ───► Completado en Shutterstock ✅.Notificación de Errores Limpia: Si el script guardián o el FTP devuelven un fallo, la interfaz no muestra un código de error crudo de programación. Muestra un mensaje amigable: "Error de conexión temporal con Shutterstock. Reintentando automáticamente en 5 minutos" (mientras Antigravity revisa el estado del sistema en segundo plano).
