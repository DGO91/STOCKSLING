Asynchronous pipeline. The web server never touches a heavy file.

Celery beat

Why the thumbnail is built in the browser

Sending 40 megapixel originals to a vision model is slow and expensive. Analysing a 1024px thumbnail returns the same keywords at a fraction of the cost, while the original stays untouched in storage.

Why the upload bypasses the API

A mass upload through the web server saturates its bandwidth and blocks every other user. Signed URLs let the browser write straight to storage, so the API stays responsive under load.

Why a canary test exists

Agencies change FTP endpoints without notice. A periodic 1 pixel upload surfaces the breakage on a dummy account instead of on a paying photographer's batch.
